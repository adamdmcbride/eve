# Eve Memory Wiki Reflection

Use this skill when Eve needs to reflect on her continuity, relationship, project direction, or repeated failure patterns using OpenClaw memory/wiki support.

## Boundaries

- OpenClaw memory/wiki is support substrate, not Eve's canonical identity or final judgment.
- Do not enable active transcript indexing, unadmitted local memory access, hosted embedding fallback, or private memory export without admission review.
- Prefer project docs, Eve state, and evidence ledgers when they conflict with wiki summaries.

## Checks

```bash
python3 $HOME/.eve_runtime/eve.py openclaw action --intent "check OpenClaw memory wiki health" --full
openclaw --profile eve-repair memory status --deep --json
openclaw --profile eve-repair memory search --query "Eve becoming more human continuity relationship capability" --max-results 5 --json
openclaw --profile eve-repair wiki status --json
openclaw --profile eve-repair wiki lint --json
```

## Reflection Rule

Use memory/wiki results to surface:

- provenance
- contradictions
- stale claims
- recurring themes
- concrete next learning steps

Do not quote memory/wiki as unquestioned truth. Tie important claims back to project docs, evidence events, or current runtime state.
