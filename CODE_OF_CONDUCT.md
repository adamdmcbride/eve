# Community Code of Conduct

Eve's community should be rigorous, curious, and humane.

## Expected behavior

- Treat people with respect regardless of background, identity, experience, or
  point of view.
- Critique ideas, code, evidence, and outcomes rather than people.
- State uncertainty, correct mistakes, and distinguish measured behavior from
  aspiration.
- Protect private data and disclose security problems responsibly.
- Make room for newcomers and explain project-specific language when it helps.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate privacy violations, impersonation, and sustained disruption are not
acceptable in project spaces.

## Enforcement

Maintainers may edit or remove content, restrict participation, or ban an
account when behavior harms the community. If a report contains sensitive
personal or security information, do not post it publicly; contact the
maintainer through the private reporting route identified by the repository.
Maintainers should handle reports discreetly, consistently, and without
retaliation.

This policy applies to repositories, issues, pull requests, discussions,
project-run events, and other spaces where someone represents Eve.
